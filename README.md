# Termaker
Termaker - library for creating terminal applications and games

## Build

* Move "termaker.c" and "termaker.h" into your project's directory
* Add '#include "termaker.h"' to top of the file and compile with a main program:

```
gcc <your args> termaker.c <your files> <your args>
```
